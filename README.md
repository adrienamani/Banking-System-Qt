# Banking System - Qt

A C++ Qt application that implements a basic banking system.

## Features

- Balance enquiries
- Deposits
- Withdrawals
- Transaction management

## Technologies

- C++
- Qt
- Qt Creator
- Git/GitHub

## Project Structure

- `main.cpp` - Application entry point
- `balanceenquiry.cpp/.h` - Balance enquiry functionality
- `deposit.cpp/.h` - Deposit functionality
- `withdrawal.cpp/.h` - Withdrawal functionality
- `transaction.cpp/.h` - Transaction functionality

## Purpose

This project was developed as part of my university coursework to demonstrate
object-oriented programming and GUI application development using C++ and Qt.
